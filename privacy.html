개인정보처리방침

시행일: 2026년 11월 1일

TopHi YouTube Videos(이하 "앱")는 운영자 본인의 YouTube 채널에 영상을 자동 업로드하기 위한 개인용 프로그램입니다. 본 방침은 앱이 Google 계정 정보를 어떻게 다루는지 설명합니다.

1. 수집·이용하는 정보

  • Google OAuth 인증을 통해 발급된 액세스 토큰 및 갱신 토큰
  • YouTube Data API 범위(youtube.force-ssl)를 통한 영상 업로드, 영상 메타데이터(제목·설명·태그) 설정, 댓글 작성, 채널 기본 정보 조회

앱은 시청자, 구독자 또는 제3자의 개인정보를 수집하지 않습니다.

2. 이용 목적

수집한 토큰과 권한은 오직 운영자 본인의 채널에 영상을 업로드하고 그 메타데이터를 설정하는 데에만 사용됩니다.

3. 보관 및 보호

인증 토큰은 운영자의 로컬 컴퓨터(또는 운영자가 관리하는 자동화 환경)에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.

4. 제3자 제공

앱은 Google 사용자 데이터를 제3자에게 판매·제공·공유하지 않습니다. 영상 제작에 사용되는 시장 데이터와 뉴스는 공개 API에서 가져오며 Google 계정 정보와 결합되지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱의 Google API 정보 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

6. 권한 철회 및 삭제

운영자는 언제든지 Google 계정 권한 페이지에서 앱의 액세스를 해제할 수 있으며, 로컬에 저장된 토큰 파일을 삭제하면 모든 저장 정보가 제거됩니다.
